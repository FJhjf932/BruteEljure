# ===========SCRIPT===========
Оно отправляет Post запросы с заполненными логином и следующим паролем в brute_{id}.txt (Работает в онлайн режиме)
Хоть и код меняет User-agent на рандомный, этого точно не хватит для анонимности.
Есть два файла: proshiv.py и obraz.py.
Запустите proshiv.py, Введите сколько скриптов одновременно будет работать, потом логин. Он начнёт делить ваш
brute.txt который должен быть возле proshiv.py и obraz.py. после этого он сделает отдельно скрипты для каждой
новой brute_{N}.txt. После успешного деление скрипт proshiv.py закончит свою работу и вам остаётся запустить
одновременно все новые скрипты (temp/brute_{id}.py) для ускорения перебора (как я сказал он будет очень медлен-
ным потому что он делает вход напрямую на сайт, а не перебирает хэш офлайн. Эти действия легко отследить.)
